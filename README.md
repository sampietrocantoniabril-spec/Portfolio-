## 🚀 Cómo Usar

### Localmente

1. Clona el repositorio:
```bash
git clone https://github.com/sampietrocantoniabril-spec/Portfolio-.git
cd Portfolio-
```

2. Abre `index.html` en tu navegador

### En Vercel

1. Conéctate a tu cuenta de Vercel
2. Selecciona "Import Project" → "Import Git Repository"
3. Ingresa la URL de tu repositorio: `https://github.com/sampietrocantoniabril-spec/Portfolio-`
4. Haz clic en "Deploy"

¡Tu portafolio estará en línea en segundos! 🎉

## 🔧 Personalización

### Cambiar Colores

Edita las variables en `styles.css`:
```css
:root {
    --primary-color: #2c3e50;
    --secondary-color: #3498db;
    --accent-color: #e74c3c;
    /* ... más variables */
}
```

### Agregar Proyectos

En `index.html`, reemplaza la sección de proyectos vacía con tus propios proyectos:
```html
<div class="project-card">
    <h3>Nombre del Proyecto</h3>
    <p>Descripción</p>
    <a href="#">Ver más</a>
</div>
```

### Cambiar Información Personal

Edita los datos en el archivo `index.html` bajo cada sección correspondiente.
